# typesafe-ai

This skill guides agents building with **TypeSafe** System One models (such as Jev): typed judgments and probabilities - Choice, Noul, and Score - that application code can compose for routing, ranking, extraction, and verification.

The skill points agents at the live docs (<https://docs.typesafe.ai/llms.txt>) as the source of truth rather than embedding API details.
